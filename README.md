# ptb-tree-map
Interactive map to display Plant N Boom trees by user_id or email, powered by Leaflet.js and PostgreSQL (read-only).

## Waar zijn de bomen? campaign

See [campaign implementation and rollout](docs/waar_zijn_de_bomen.md) for the production purchase flow, hidden €0 test campaign, fake-tree pool, map verification, PostgreSQL identification, and required Shopify/Zapier configuration. The migration and theme files are prepared for review; external activation and production data changes have not been performed.
